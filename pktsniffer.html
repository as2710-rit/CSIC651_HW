pktsniffer module¶

A simple packet sniffer built on top of Scapy.

Reads packets from a pcap file, optionally filters them using a small tcpdump-like expression language (port / ip / tcp / udp / icmp / arp / net / host, combinable with ‘and’, ‘or’, and ‘not’), and prints Ethernet, IP, and transport-layer (TCP/UDP/ICMP/ICMPv6) header information as pandas DataFrames.

pktsniffer.normalize_tokens(raw_tokens)[source]¶

Strip a leading ‘-’ or ‘–’ from filter keywords.

This allows both ‘-c’ and ‘–c’ style usage to be accepted.

pktsniffer.parse_filter_tokens(tokens)[source]¶

Parse a flat list of filter tokens into a list of clause dicts.

Grammar supported (case-insensitive):

<primitive>      := ip | tcp | udp | icmp | arp
<primitive-arg>  := port <number> | net <addr>[/<prefixlen>] | host <addr>
<clause>         := [not] (<primitive> | <primitive-arg>)
<expression>     := <clause> [(and|or) <clause>]*

Clauses are combined left-to-right using the connector that precedes them; if no connector is given between two clauses, ‘and’ is assumed (this mirrors how most simple pcap-filter expressions are written).
